# UIKit page recipes

Pick one `NV*` recipe per screen. Compose inside it (`.nuvyn/reference/ui-and-catalog.md`). Empty self-closing recipe = demo seed.

## Auth and onboarding

`NVSignInView` `NVSignUpView` `NVForgotPasswordView` `NVResetPasswordView` `NVSocialSignInView` `NVTabbedAuthView` `NVProfileSetupView` `NVWalkthroughView` `NVOnboardingPermissionsView` `NVPinLockView`

## Commerce

`NVCategoryView` `NVCatalogView` `NVProductHomeView` `NVProductDetailView` `NVCartView` `NVWishlistView` `NVCheckoutView` `NVCardPaymentView` `NVSavedCardsView` `NVPaymentResultView` `NVOrdersView` `NVOrderHistoryView` `NVOrderSummaryView` `NVSubscriptionView`

## Content / social

`NVArticleFeedView` `NVArticleDetailView` `NVInboxView` `NVConversationView` `NVDashboardView` `NVSettingsView` `NVNotificationsView` `NVBookingView` `NVHealthProfileView`

## Status / field

`NVStatusView` `NVDocumentsView` `NVConflictResolveView` `NVStoreLocatorView` `NVInvoiceView` `NVReceiptView` `NVAddressFormView` `NVPinLockView`

## Compose when no recipe fits

`NVCard` `NVCollectionView` `NVDataForm` `NVEmptyView` `NVBusyIndicator` `NVToast` `NVBottomSheet` `NVTabView` `NVBottomNavigation`
